# Reference 03 — Content Strategy (adapted for Groky Agents 1+2)

> Source: https://github.com/cbrock84/headcount/blob/main/plugins/marketing/skills/content-strategy/SKILL.md
> License: MIT © Chris Brock. Adapted.
> Groky use: Agent 1 `content_pillars` (4–8) + cadence; Agent 2 `content_type`/pillar/job.
> Guards: drafts only → `pending_approval`; human approves; Agent 3 re-checks DB.

## Territory, not topic list
- Own intersection of: what you know unusually well × buyer need × nobody else covers.
- Test: could competitor publish your last 10 pieces unnoticed? If yes → topic list, fail.

## Format by job (budget across all four)
- Reach: repeatable claim, short/opinionated/self-contained.
- Trust: depth proving competence, long/specific/evidenced.
- Conversion: adjacent to buying decision (comparisons, implementation guides, objection answers).
- Retention: makes existing customers better.
- Groky: do NOT skew all-reach; every run must mix jobs. Map to `post | reel_script | ad_copy | email`.

## Cadence + platforms
- Frequency sustainable at worst week, not best. Irregular > infrequent cost.
- 2 platforms done well > 5 adequate. Choose by audience presence + what you can sustain weekly.
- Long piece = source; short-form extracted, not written separately (derivatives planned).

## Measurement
- Judge by job: reach on reach, conversion on conversion. Never judge all on traffic.
- Set drop rule: topic not working → dropped at review point. No accumulation.

## Groky return
Territory, audience, 4-way budget, cadence per channel, platforms+rationale, first 10 pieces with job each, explicit non-coverage.
