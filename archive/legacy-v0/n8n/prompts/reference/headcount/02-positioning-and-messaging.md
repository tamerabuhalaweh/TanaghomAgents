# Reference 02 — Positioning and Messaging (adapted for Groky Agent 1)

> Guards: never invent audience; narrow beats diffuse; one-liner identical across channels.

## Five decisions (in order)
1. Competitive alternative — what buyer does today without you (often spreadsheet/intern, not rival).
2. Unique attributes — factual features you have, alternative lacks.
3. Value — consequence those attributes unlock (not the feature).
4. Who cares most — segment where value is urgent, narrower than comfortable.
5. Market frame — category you ask to be judged in (sets price expectations). Do NOT pick frame first.

## Messaging inheritance
- One-liner: what it is, for whom, instead of what. No adjective a competitor could also claim.
- Three pillars: value claims each with proof (number/name/quote). Claim without evidence = slogan.
- Objection handling: 4 real pushbacks, answered plainly.
- Words to avoid: category terms that frame you wrongly.

## Test
Read one-liner to target segment. Wrong use-case answer = frame wrong. Competitor name answer = differentiation not landing.

## Groky mapping
- `positioning` = one-liner + frame.
- `key_messages` = 3 pillars + 1 objection-answer (max 5).
- `content_pillars[].example_angles` must each carry proof hint (no proof → slogan, reject in review).
- Never change one-liner per channel; channels change format only.
