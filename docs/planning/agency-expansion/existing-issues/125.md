- [ ] Create campaign → brief → strategy → three drafts → human approval → approved Content Library.

- [ ] GHL ingress: signed test-contact message → one durable event/job → grounded proposal → Supervisor Inbox (#54).
- [ ] Human takeover/assign/pause/resume-to-AI and no double-send authority race (#53).

- [ ] Import approved de-identified baseline, run shadow comparison, and record owner threshold decision (#56).
- [ ] Verify reports, agent registry, monitoring, audit timeline, and customer-visible blockers.
- [ ] Record defects, retest fixes, and obtain written customer signoff.

## Safety boundaries
- No credential in Git, n8n export, Compose, browser response, issue, or logs.
- No automatic publishing, mass outreach, production spend, or unrelated-contact messaging.
- No SmartLabs, SmartCC, voice, Gemma service, Nginx, or firewall modification.
- Keep polling schedules disabled and provider emergency stops active except for separately authorized bounded test windows.
- Provider timeout/indeterminate results are reconciled; never blindly retried.

## Acceptance
- Every checked step links timestamped evidence and operator identity.
- All defects classified as release-blocking, accepted limitation, or post-handover roadmap.
- Customer confirms credentials/channels remain customer-managed.
- Customer signs off the agreed release scope and activation mode.
