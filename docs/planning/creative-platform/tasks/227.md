## Review corrections (senior review 2026-10-08, all five blockers fixed)

1. Globals read-only: dropped `p_global` from `create_creative_template`
   (4-arg, org-implied); `set_creative_template_active` rejects NULL-org
   rows; server returns 400 on `global:true`; UI checkbox removed.
2. Upload decoupled: `register_upload_asset` performs dedicated
   enqueue→claim→run→register→complete transitions inline (no generic
   claimant, no control gate); works while stopped; exact-job targeting.
3. Idempotency-first upload: reserve precedes storage write; replay
   writes nothing; `stored` flag + `O_EXCL` writes guarantee cleanup on
   every non-committed path (proven by trigger-injected post-write
   failure + file census).
4. Preview hardened: PNG/JPEG/WebP allowlist only, `nosniff`, HTML 415;
   same-origin inline HTML can never execute.
5. Version races closed: `FOR UPDATE` parent lock (brand kits) +
   scope-keyed advisory xact lock (templates); concurrent creates
   proven to yield v2/v3 and v1/v2.
