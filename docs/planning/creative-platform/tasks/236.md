## Architecture (carried from P2a/P3)

- Durable jobs, capability `video`, lane `gpu_video` (network-bound
  provider work, mirroring P2a's `gpu_image`).
- Least-privilege worker: filtered `claim_creative_video_job()`,
  tenant-checked source resolution, EXECUTE-only (no table SELECTs).
- Async provider calls metered per attempt in
  `creative_provider_calls`; never blind-retry indeterminate state.
- SSRF-safe download reuses the P2a boundary (allowlist, DNS
  A/AAAA pinning, private/link-local/metadata rejection, Host/SNI
  preservation, redirect validation, HTTPS-only outside test mode).
- Provider MP4s validated (container/track/codec/duration/dims;
  allowlist `mp4v`+`avc1`, never trusting MIME/filename).
- Full provider/model/cost provenance; reviewer approve/reject;
  no publishing. Flags default OFF (`GENERATIVE_VIDEO_ENABLED`).
