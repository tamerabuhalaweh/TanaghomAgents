## Architecture (Creative Runtime native)

- Durable jobs: capability `product_shoot`, lane `cpu`,
  `params.operation='segment'` (no new capability needed; `segment`
  is already in the provider-calls operation vocabulary). Filtered
  `claim_creative_segment_job()` selects product_shoot/cpu/segment
  only, so compose jobs are never touched.
- Least-privilege Python bridge: fixed argv, pinned model + weights
  allowlist, bounded JSON protocol over stdio, no shell, no network
  after provisioning, timeouts, memory caps, EXECUTE-only worker.
- Deterministic local engine (sharp-based) for test/E2E evidence +
  mask refinement primitives (feather/erode/threshold).
- Masks + cutouts persist as immutable versions with full
  provenance; source never mutated; fidelity system reused.
