# Task 234 — P3 Motion Studio (motion graphics only)

Owner: Muse (sole implementation agent). Branch
`feature/creative-p3-motion-studio` from `origin/main@3a837a3`.
Issue: #234. PR: (to open, linked to #234).

## Scope

Motion graphics ONLY: animate an existing approved/editable design
(ad/carousel) into an MP4 private asset. No generative video, no talking
head, no voice/TTS, no music, no billing/credits, no production deploy,
no P4 in this PR.

## User flow

Design → Motion Studio → animation preset → per-element motion →
duration/timeline → preview → render → MP4 private asset →
reviewer approve/reject. No publish control anywhere.

## Architecture (carried from P2b)

- Source stays structured JSON; motion documents REFERENCE design
  template id+version (never duplicate design source).
- Durable Creative Runtime jobs, capability `motion`, lane `cpu`.
- Least-privilege worker: new controlled functions only, EXECUTE-only
  role, capability-filtered claim `claim_creative_motion_job()`.
- Offline render, zero network egress (route-abort + JS-disabled
  capture, fixed FFmpeg argv, no shell).
- No arbitrary HTML/JS/CSS; no FFmpeg argument/filter injection;
  strict codec/container allowlist; private storage only.
- Full provenance/audit; flags default OFF
  (`CREATIVE_STUDIO_ENABLED`, `MOTION_STUDIO_ENABLED`).
- Arabic: browser-shaped Unicode text, no diffusion, RTL-aware
  entrances, mixed-language, numerals/punctuation, multiline, 9:16 story.

## Migration

`0040_creative_motion_render`: controlled functions only

## Engine decision

See `234-motion-engine.md`: in-house deterministic timeline
(CSS keyframes frozen per frame via negative-delay paused animations,
Chromium PNG frames streamed incrementally, FFmpeg image2pipe→MP4 with
fixed argv, pure-JS MP4 validation incl. stsd codec). Remotion rejected
(proprietary per-render fees). Motion Canvas MIT-noted but rejected
(code-execution model vs no-arbitrary-JS boundary, dependency weight,
no design-doc reuse). FFmpeg is a deployment-provided binary, never
bundled; codec allowlist `mpeg4` (native, no GPL encoder lib);
libx264 stays rejected pending legal.
