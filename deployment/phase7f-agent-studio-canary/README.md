# Phase 7F Agent Studio bilingual canary

This package proves one English and one Arabic `success` scenario for one
exact, validated Agent Studio version through the installed shared n8n runtime.

It is simulation-only. The parent runner stays inactive. The endpoint-free,
schedule-free Simulation Dispatcher is temporarily published in n8n only
around each reviewed parent CLI call and is immediately unpublished again.
This n8n runtime publication is not content or social publishing. The canary
does not enable a provider adapter, call Postiz or GHL, publish content,
contact a lead, create a CRM record, spend money, or promote the agent. The
shared runtime emergency stop is restored after each one-off CLI execution.

The installed dispatcher may still contain n8n's rejected legacy empty-input
shape. If so, the authorized canary first replaces only that inactive workflow
with the reviewed `inputSource: passthrough` export. Every other workflow must
remain unchanged. Any later failure automatically restores the original
dispatcher and verifies the complete operational workflow inventory. The
corrected inactive dispatcher is retained only after the bilingual canary
passes in full.

Merging this package does not authorize production execution. Follow
`RUNBOOK.md` only after the package PR and the exact canary identity are
approved.
